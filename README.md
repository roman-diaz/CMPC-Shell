## Installation

1️⃣ Instalar dependencias

Desde la raíz del proyecto:

```bash
  pnpm install
```

## ▶️ Levantar el backend

Desde la raíz del proyecto:

```bash
 pnpm exec json-server --watch db.json --port 3001
```

## ▶️ Levantar Frontend – AppShell

Desde la raíz del proyecto:

```bash
  pnpm dev
```
